# Personal Task Tracker — Project Brief

## Сонгосон сэдэв
Сэдэв 2: Personal Task Tracker

## Зорилго
Хувийн даалгаврын менежментийн систем. Хэрэглэгч даалгавар үүсгэж, засварлаж,
устгах боломжтой. Due date, priority, label-ээр ангилах, хайх боломжтой.

## Scope
### Багтах зүйлс (In scope)
- Task CRUD (Create, Read, Update, Delete)
- Due date тохируулах
- Priority тохируулах (High, Medium, Low)
- Label/tag нэмэх
- Search & filter

### Багтахгүй зүйлс (Out of scope)
- User authentication
- Cloud sync
- Mobile app
